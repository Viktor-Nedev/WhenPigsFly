When Pigs Fly!

The game When Pigs Fly is a journey of a pig traveling through different terrains, where it must avoid obstacles along the way that are generated in different locations each time, making sure not to crash.

The longer the pig flies, the more money it earns, which the player can use to buy different pigs, wings, and effects for the pig. Additionally, for every 5,000 meters traveled, the player can unlock something new from the piggy bank in the game.

Currently, the game features four biomes — Nature, Desert, Sky, and City — each with different 3D models and a unique design.

Future plans include adding new biomes, new pigs, wings, and effects, as well as fully optimizing the game.
